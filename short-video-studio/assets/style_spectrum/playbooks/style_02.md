# style_02 导演圣经（双源逆向对齐版）

- **视觉家族定位**：极速跳剪避坑 · 通宽暗灰底框荧光绿风（原型 `arch_04_punch_talking_head`）
- **舞台范式**：`unified_single_stage`（单层一体化动态排版，高光句与桥接句共享唯一舞台，绝不在大字下叠加第二层底字幕）
- **Director 主题配置**：`theme_profile = style_02_unified`

## 一、视觉血统：字体、唯一色盘与三级字号标尺
- **推荐主字体族**：`Source Han Sans CN / Alimama ShuHeiTi` | 首选商用候选：`SourceHanSansCN-Bold.otf, NotoSansSC-Bold.ttf, AlimamaShuHeiTi-Bold.otf`
- **字族纯洁铁律**：全片（开场、高光、桥接、人后弹幕、清单）100% 使用现代无衬线粗黑体，严禁与宋体混穿。
- **唯一色盘**：主字 `#FFFFFF` | 核心高光 `#BCFF00` | 警示/痛点 `#B71C1C` | 描边 `#000000` | 底框 `rgba(0,0,0,0.70) 紧凑方底(bridge_bar) / #FFFFFF 白底胶囊(red_pill)`

| 字阶 | 剪映基准单位 | 1080p 渲染字号 | 黑盒视觉占比 | 适用表达对象 |
| :--- | :---: | :---: | :---: | :--- |
| **L1（常规/桥接）** | `11.5u` | `~69px` | 5.3% | bridge_bar（单行紧凑过渡短句）及辅助角标 |
| **L2（主讲高光）** | `16.5u` | `~99px` | 7.5% | 主高光行、清单条目、red_pill 白底红字胶囊、inline_rich 焦点词 |
| **L3（核爆锚点）** | `22.5u` | `~135px` | 10.5% | red_slam 痛点巨字、hero_lime 荧光绿焦点词、大数字主视觉 |
- **三阶对比比例**：`1.00 : 1.43 : 1.96`

## 二、字幕与动态排版规范
- **安全中心 Y 占比**：`0.76` | **单行字数上限**：`<= 8` 字 | **贴主轨切点率**：`66.7%`
- **白盒轨迹实证**：base 轨（track [5]）共 22 段，覆盖片长 98%；相邻段无缝率 95%（Δ≤1 帧，按整轨顺序算）；其中 12 段是普通字号字幕（其余 10 段被升级）；y 中位 0.76×H；字幕起点 75% 落在主轨切点 ±2 帧内（到最近切点中位 0.0s）——这套是切点驱动的重剪风格，字幕起句跟着镜头切
- **双层复读禁令**：0 复读铁律：高光大字直接承担台词表达，禁止在同时间窗底端叠加第二层小字幕；仅过渡/呼吸句显示 L1 紧凑 bridge_bar。
- **8 大一体化复合排版原语（商业与探店共通）**：
  1. `opening_triad`：开场三阶错落弹出（上 L2 白 + 中 L3 荧光绿 + 下 L2 白底红字胶囊）
  2. `left_right_punch`：左右错落对冲（L2 白与 L3 荧光绿左右张力）
  3. `giant_anchor_sub`：L3 巨字居中锚定 + 下方 L1/L2 紧凑结论
  4. `pain_slam_danmaku`：痛点 L3 `red_slam` 砸屏 + 联合人脸包络安全避头人后弹幕
  5. `stacked_dual_color`：上下双色错层叠字（L2 白 + L3 荧光绿按词触发）
  6. `list_gather_depth`：清单依次按词弹出 + 前项自动压暗留景深 + 幕尾彻底清场
  7. `number_burst_pair`：荧光绿 L3 大数字（滚数动效）+ 紧贴白字 L2 结论
  8. `inline_highlight_cta`：单行内双色双字号混排（L1 白 + L2 荧光绿重点词，严禁吞尾字）

## 三、剪辑节奏、运镜与 B-roll 选镜策略
- **白盒剪辑统计**：中位镜长 `1.13s`（P10 `0.7268s` / P90 `1.7002s`）| `<1s` 快切占比 `28.0%` | 前 3 秒切镜 `2` 刀 | 关键帧密度 `0.0/min`
- **黑盒拆解实测（rea-video）**：总时长 `29.47`s | 检测镜头 `3` 个（均长 `9.82`s）| 切换踩声音起始点比 `0.5`
- **B-roll 目标配比区间**：先验 `11%`（弹性带宽 `0%..55%`）；无实拍素材则保持 100% 口播靠复合排版 + 推拉特写撑起视觉密度；有实拍素材则严格遵循 `broll_policy` + `broll_keywords` 在物证/环境幕切入对应实拍。
- **转场规范**：`none`（95%+ 为 0 帧硬切，禁止滥用花哨内置转场）。

## 四、视觉包装、抠像与声画同步（以音定画）
- **抠像与画中画**：AI 人像抠像 `3` 段（抠像的因果是「这一镜要同时看到人和另一层画面」：人从背景提出来 → 下面垫一条不同源的副镜 → 叠加轨（render_index>0）出画。本套 3 段抠像里 3 段在叠加轨、3 段仍是全屏 scale=1（人满屏叠在满屏副镜上，抠不...）；画中画模式 `geometry_pip_window`；画面特效：无额外全局花哨滤镜，保持干净原片质感
- **黑盒叠层构成**：可见种类 `huazi, label, static_graphic, static_sticker, subtitle, title`；入场动效分布 `{'cut': 28, 'slide': 3, 'reveal': 3, 'fade': 3, 'pop': 1}`；底框出现 `2` 次
- **响度与配乐**：目标响度 `-14.0 LUFS` | 人声/BGM 信噪比 `11.5 dB` | 白盒 BPM `99.38` / 黑盒 BPM `79.5` | 双 BGM `False`
- **音效密度与触发分配**：`40.7/min`（触发分配 `{'cut': 0.6, 'flower': 0.3, 'line': 0.1, 'beat': 0.0, 'free': 0.0}`，最小间隔 `0.6s`）；黑盒卡点类型 `{'pop': 3, 'ding': 5, 'hit': 2}`

## 五、总导演执导红线（写 `03b_director_plan.json` 必守）
1. 严格按 `03b_director_tasks.json` 顺序覆盖全部 `sentence_ids`，不遗漏不重复。
2. 视觉短词（`headline`/`items`/`accent_token`）去掉标点每行不超过 7 字，必须完全出自该幕口播原话，数字与量词 100% 原文可核对。
3. `slow_push_115` 严禁连续两幕连推造成弹回；关键对比/反转幕使用 `jump_closeup`（1.22× 硬切特写）或 `slow_pull_115` 形成起伏。
4. 每幕 `visual_copy` 的入场与子项偏移通过词级时间戳 `words` 映射实现「声画 0ms 咬合，不提前剧透未说出口的条目」。
5. 若存在高光实拍素材，凡口播提及具体食物/空间/动作/场景切换时设置 `broll_policy: allow_verified_broll` 并填入精确 `broll_keywords`；开篇锚点、痛点砸屏与人后弹幕严格设 `lock_aroll`。
