# 动效设计、品牌 Promo 与 UI 演示工艺规范（Motion & Promo Craft）

> 适用场景：开篇动态字体、品牌/门店宣传卡、数据卡片、App 与控制台 UI 演示、实物产品包装卡。

## 一、 先定设计系统，再写第一行动画

动效开始前先锁定 4 项约束（均应写入 `00_code_spec.json`）：
1. **克制色板**：`1` 主背景 + `1` 表面卡底 + `1–2` 高对比强调色 + 中性灰文本（可直接复用 `style_01`~`style_20` 或 `warm_food / craft_paper / dark_tech` 三大语域）。禁止随性新增渐变杂色。
2. **双字体等级**：最多 `1` 展示标题字体 + `1` 正文字体（必须通过 `common.is_verified_commercial_font` 开源商用认证）。推荐 1080p 阶梯字号：`主标 ≥ 64px` / `重点卡 ≥ 44px` / `辅助标签 ≥ 28px`。
3. **跨画幅安全边距**：
   - **9:16 竖屏（本仓默认主轨）**：有效文案/LOGO 严守 `SAFE_ZONE`（`x ∈ [60, 880]`、`y ∈ [160, 1480]`），并为双通道字幕预留 `y ∈ [1180, 1468]` 洁净底带。
   - **16:9 横屏**：四周保留至少 `5%` 外边距。
4. **单一串联母题（Motif）**：全片转场尽量围绕同一个视觉母题衍生（如滑动毛玻璃卡面、高亮游标线、折页翻动），不要混杂五花八门的淡入擦除。

## 二、 物理动效语法与闭式阻尼弹簧

告别机械匀速与千篇一律线性渐变，关键动作应体现**五段式质感**：
> **微预备（Anticipation）→ 果断发力（Move）→ 触达接触（Contact）→ 轻微过冲回弹（Overshoot & Settle）→ 可读停留（Hold）**

### 确定性闭式阻尼弹簧公式
直接作为 `t` 的纯函数计算，不保存上一帧速度/位置状态，支持随意 seek 任意帧：

```python
# Python 参考签名（见 generate_code_broll.damped_spring）
# t <= t0 返回 0.0；zeta < 1.0 时在 1.0 附近自然过冲收敛
def damped_spring(t: float, t0: float = 0.0, freq: float = 2.2, zeta: float = 0.58) -> float:
    x = max(0.0, t - t0)
    w = 2.0 * math.pi * freq
    wd = w * math.sqrt(max(1e-6, 1.0 - zeta * zeta))
    return 1.0 - math.exp(-zeta * w * x) * (math.cos(wd * x) + (zeta * w / wd) * math.sin(wd * x))
```

### 节奏与编排习惯
- **交错入场（Stagger）**：同组卡片、列表或柱状条错开 `2–5 帧`（约 `0.07–0.16s`）依次弹入，禁止全体元件同一帧齐刷刷出现。
- **单一焦点法则**：任意时刻场上只有一个视觉主事件在运动，次要背景退居安静衬托位置。
- **快切靠精简字数，不靠压缩停留**：快节奏短片每 `1–2s` 换一次状态，但必须靠缩短文案做到“一看即懂”，绝不能把句子停留压缩到人眼来不及读完。
- **收尾定格**：末尾 CTA 或品牌收束帧至少保留足够阅读两遍的稳定构图。

## 三、 文案精准与中文可读停留底线

1. **逐字保真**：屏幕出现的一切中文、数值、价格、折扣码必须与 `00_code_spec.json` / `03_audio_events.json` 完全一致；严禁自动模型幻觉补写“全网最低”“效果翻倍”等未授权文案。
2. **可读停留计算公式**：
   - **中文文案**（卡片静止展示净时长）：`hold_sec >= max(1.6, chars / 4.5 + 1.5)`；开篇或收尾标题卡不少于 `2.0s`。
   - **英文文案**：`hold_sec >= letters / 15 + 1.5`。
3. **动态字体还原约束**：文字若在动画过程发生拉伸、切割或渐显，结束入场后必须抵达**完整无遮挡、高对比**状态并保持可读停留。
4. **先测量再落位**：始终通过 Pillow `textbbox` 或浏览器 `getBoundingClientRect` 实测换行高度与宽度，禁止凭字数估算坐标导致越界。

## 四、 实拍、Logo 与 UI 截图保真纪律

- **Logo / 商标图标**：原比例等比缩放，禁止变色、描边变形、裁剪或私自矢量重绘，四周留足呼吸空间。
- **UI 截图演示与像素叠图核对**：
  - 截图中展现的功能面板、按钮颜色、状态数据必须严格忠于原截图；
  - 若要让某个指标（如数字递增、进度条填满）动起来，只用代码重绘该局部控件并与原截图做 50% 透明度叠图校准；外部数值改动（如 `3/5 → 4/5`）要全片同步更新。
- **产品实拍图 / 去背抠图**：
  - 保持照片影调质感，禁止漫画化或风格迁移扭曲原产品外观；
  - 浅色底抠图需对边缘做轻量向内收缩 (`1px`) + 羽化 (`1–2px`)，放在深色底图上核查无白边光晕，且禁止过度放大超出原图清晰度。
- **内嵌参考视频片段**：一律按 [code-video-methodology.md](code-video-methodology.md) 执行预抽 JPG 帧序列 + `seek(t)` 映射，并抽 2–3 个时间点核对源视频帧与成片帧毫秒一致。
