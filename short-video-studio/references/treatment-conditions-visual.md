# 视觉类处理的触发条件：转场 / 抠像 / 变速 / 贴纸 / 特效

最后更新：2026-11-24 · 真值来源 24 套源草稿（`forensic/decrypted/*`，只读）

这份文档回答一个具体问题：**这套风格里，抠像/变速/贴纸/转场到底在什么条件下才允许出现？
作用域是哪些镜头？**

背景是用户的原话：

> 「风格模版应该好好抽象下这些音效、花字之类的是要在什么情况下才会出现，调用的原则是怎样，
> 作用域又是怎样，而不是无脑的硬植入。」
> 「不仅仅是音效和花字，还有转场、抠像、变速等等模版里包含的那些针对具体素材元素的处理，
> 都是要提炼出真正的风格条件才是。」

原来的错法：风格里有这个能力，就每一镜都套。实测事故是 style_21 有抠像，于是给 15 个 A-roll
全挂了 `cutout`，把「主持人举着效果图讲解」那一镜的图抠掉了，只剩一双带白边的双手。
现在的做法：**能力只说明这套风格用过这个手法；用不用在这一镜，要看这一镜的画面满足不满足条件。**

规则不是写在代码里的常数，而是从 24 套真源草稿量出来的，落在
`forensic/style_trigger_rules_visual.json`（24 套 × 五节）。运行时唯一判定口是
`scripts/treatment_policy.py`，改阈值只改数据，不改代码。

---

## 一、触发条件（可执行判定）

五类处理各有自己的成立条件，全部写成「判定键 + 阈值」，由 `treatment_policy` 解释执行。
**任何一条不满足 → 不套**，并给出一句能直接念给用户听的理由。

### 1. 转场 transition

真值：**24 套源草稿转场数全部 = 0**（逐段 `extra_material_refs` 指向 transition 的引用也查了，
双向核对，见下表与 JSON 的 `evidence.truth_transition_count`）。所以这套语料里「转场」不是一个
风格特征，而是**默认不存在的东西**——套用端不许自己发明。

| 判定 | 条件 | 判定键 |
|---|---|---|
| 允许（任一成立） | 用户显式放行（`EDL.transition_whitelist` 非空） | `user_explicit` |
| 允许（任一成立） | 素材本身自带溶接（同源叠化帧），不是后期贴的转场素材 | `source_native_overlap` |
| 允许（任一成立） | 章节断点：两侧台词结束且静音 ≥0.3s | `chapter_break` |
| 禁止（优先级更高） | 句内换气点 / 快切串里的刀 / 开场 3 秒 / 抠像层进出点 | `cut_kind ∈ scope.forbid` |

事实依据：全库 113 份解密草稿里有 17 份带转场（44 处，`叠化`/`泡泡模糊`/`故障` …
时长 0.13–1.0s，中位 0.33s），**但没有一份属于这 24 套**。也就是说：转场在这批语料里是
「别的流派的手法」，硬套进来就是把别人的节奏贴到这套风格上。

### 2. 抠像 / 画中画 cutout

真值：18 套有抠像、6 套完全没有（style_04/06/08/15/17/20）。其中 17 套的抠像落在**叠加的人物层**
（不是主轨），人物层被抠比例从 4%（style_09）到 100%（style_02/03/12/14/16/21）。
**真值 72 段抠像里，只有 2 段（3%）与「指认画面」的台词同框**——这条是「讲图不抠像」的量化依据。

必须同时满足：

| # | 条件 | 判定键 | 为什么 |
|---|---|---|---|
| 1 | 这套风格真值里出现过抠像（>0 段） | `style_truth_positive` | 真值 0 段的风格，一段也不许抠 |
| 2 | 只挂在真人出镜层（a_roll） | `track_role_in` | B-roll/图卡/照片没有可抠的人像主体 |
| 3 | 画面里检出人脸 | `face_present` | 手部特写、空镜、图纸特写抠了也没有主体 |
| 4 | 人脸够大（高 ≥12%、宽 ≥7%） | `face_min_size` | 人在远处时抠出来只是一团糊 |
| 5 | 画面判读里没有图纸/屏幕/展板/样张/菜单… | `no_display_terms` | 观众唯一该看的东西会被一起抠掉（本次事故的直接原因） |
| 6 | 台词不是「指认画面」型（这个/看/效果/图纸…） | `no_deictic_terms` | 台词在指画面时，画面本身才是信息 |
| 7 | 副镜与主镜不同源 | `secondary_distinct` | 同源套娃 = 自己叠自己 |
| 8 | 单镜时长 ≤ 该风格真值最长抠像段 ×1.25 | `duration_le` | 长镜一直抠像，观众会忘了下面压着的那层 |
| 9 | 累计抠像时长 ≤ 人物层时长 × 真值比例 ×1.15 | `cutout_budget_left` | 密度按「人物层」算，不按全片算（按全片算会虚高到不起作用） |
| 10 | 连续段数 ≤ 真值连续段数 ×1.25 | `run_budget` | 真值里抠像是**成段**出现的；每镜来回开关本身就是画面变化 |
| 11 | 多脸时主体脸要明显更大 | `subject_dominant` | 否则会把旁人抠出半张脸 |

判定 3–5 的实现只有一份（`scripts/pip_policy.py` 里的 `decide()`），`treatment_policy` 用同一份阈值调用它，
不存在两套口径；判定 6–11 是风格层，只在 `treatment_policy` 里。

### 3. 变速 speed

真值：24 套里只有 **style_01（1 段）与 style_24（3 段）**有变速，全部 2.0×、全部在叠加/B-roll 层，
主轨 0 段；单段 1.03–2.55s。其余 22 套全片原速。

| # | 条件 | 判定键 | 为什么 |
|---|---|---|---|
| 1 | 这套风格真值里出现过变速 | `style_truth_positive` | 22 套真值 0 段 → 一段也不许变 |
| 2 | 只作用于 B-roll / 叠加层 | `track_role_in` | **A-roll 口播永远原速**：口型与字音一拆就穿帮 |
| 3 | 单段时长在该风格真值带内 | `duration_between` | 太短的段变速看不出来，只听到声音变形 |
| 4 | 倍速只取真值出现过的值（±0.15） | `speed_value_in` | 不自己发明 1.35×/3× |
| 5 | 素材剩余长度够吃下「时长 × 倍速」 | `source_headroom` | 余量不足会把同一段画面播两遍 |

另外流水线里还有一道 `apply_speed_policy` 的**同源帧冲突**检查：变速要多吃的素材帧不能是别的
镜头已在用的帧（否则成片等于重复播同一段画面，质检还会判成「倒带」）。

### 4. 叠加层 / 贴纸 overlay

真值：11 套有贴纸（0–3 个/片），单条 0.55–13.2s。**6 套的贴纸 100% 落在切点上**
（style_02/05/07/14/19），另外 5 套本来就飘在切点后 0.4–1.5s（style_08/13/15/17/18/21）——
所以「必须贴切点」是**按套**的规则，不能拿谁的去套别人。10/11 套的贴纸与当刻花字同框（style_07 例外）。

| # | 条件 | 判定键 | 为什么 |
|---|---|---|---|
| 1 | 这套风格真值里有贴纸 | `style_truth_positive` | 13 套真值 0 个 → 不贴 |
| 2 | 起点贴切点（±0.25s）*仅当该套真值贴切点率 ≥60%* | `near_cut` | 跟着新镜一起进场，不悬在镜中间凭空出现 |
| 3 | 当刻屏幕上有对应花字/字幕 *仅当该套真值同框率 ≥80%* | `paired_with_text` | 孤立贴纸在源草稿里不存在，观众只觉得脏 |
| 4 | 条数 ≤ 真值密度 ×1.5 | `count_budget` | 贴纸是点缀，不是边框 |
| 5 | 单条 ≤ 真值最长贴纸 ×1.25 | `duration_le` | 贴纸是「闪一下」不是「一直挂着」 |

### 5. 画面特效 effect

真值：**24 套里只有 7 套有画面特效**（style_02/04/08/15/17/20/21），单片 1–4 处，
单处 0.17–6.03s，累计覆盖 ≤20% 片长。位置遍及全片（style_02 在 37%、style_04 在 79%），
**不是"只在 hook"**——但 ≤0.6s 的瞬时特效（模糊/颤抖/聚光灯）全部贴在切点上。

| # | 条件 | 判定键 | 为什么 |
|---|---|---|---|
| 1 | 这套风格真值里有画面特效 | `style_truth_positive` | 17 套真值 0 个 → 不加 |
| 2 | 单处时长 ≤ 真值最长特效 ×1.25 | `duration_le` | 特效盖一个段落，不盖全片 |
| 3 | ≤0.6s 的瞬时特效必须贴切点（±0.25s） | `instant_near_cut` | 否则渲染出来像闪帧/坏帧 |
| 4 | 累计覆盖 ≤ 真值覆盖 ×1.25（且 ≤35%） | `coverage_budget_left` | 不许整片挂滤镜 |
| 5 | 条数 ≤ 真值密度 ×1.5 | `count_budget` | 特效是段落级冲击，不是循环贴纸 |

## 二、调用原则

1. **能力 ≠ 指令。** 真值里的「这套风格有抠像/变速」只说明这个手法存在，说明不了密度，
   更说明不了落在哪一镜。具体落点必须由**这一镜的内容**决定。
2. **内容优先于风格。** 当画面里正给人看某个东西（图纸/效果图/屏幕/展板/样张/菜单）、
   或台词正在指认画面（这个/看/效果/颜色）时，任何会改变画面完整性的手法（抠像、推近、裁切）
   一律让步——风格少一个动作，比观众看不见该看的东西要好。
3. **密度按真值比例算，不按绝对条数算。** 15.6s 的片子里 7 段抠像（61%）是对的，
   63s 的片子里照抄 7 段（11%）反而更不像；所以预算一律×比例，见 `limits`。
4. **量不到就不套。** 规则文件缺、风格缺节、判定抛异常 → 一律按「不套」处理，
   并在 EDL/报告里写明原因。宁可少一个手法，不许硬植入。
5. **被拒也要记账。** 每一处处理（放行或拒绝）都带 `reason`（人话）与 `scope`（作用域），
   落在 `04_edl.json` 的 `cutout_gate.rows` / `treatment_policy.*.rows`、
   或套用端 `apply_replica_template` 报告的 `treatment_policy.*.rows`。
6. **降级不是跳过。** 抠像被拒时，仍按该风格真值摆几何（推近/窗口）；只有「画面里正给人看东西」
   这种内容关键镜头才连推近一起取消，整张画面原样给完。

## 三、作用域

| 处理 | 允许的镜头 | 禁止的镜头 / 位置 | 真值依据 |
|---|---|---|---|
| 转场 | 章节断点、用户显式放行点、素材自带溶接处 | 句内换气点、快切串、开场 3s、抠像层进出点 | 24 套转场 = 0 |
| 抠像 | a_roll（真人层），压在一层异源画面之上 | b_roll / code_broll / photo / 贴纸层；多脸且主体过小；正在给人看东西的镜头 | 18/24 套有，17/24 套落叠加层 |
| 变速 | b_roll / overlay_card | a_roll（口播）、text、sticker、photo | 仅 style_01/24 有，主轨 0 段 |
| 贴纸 / 叠加层 | 切点边界、B-roll 层、有配套花字处 | 口播正脸全屏压脸、真值无贴纸的风格 | 11/24 套有，0–3 条/片 |
| 画面特效 | 单段氛围（暗角/噪点/边框）、冲击切点（模糊/颤抖/聚光灯） | 整片挂滤镜、盖住人讲话的正脸、瞬时特效不贴切点 | 7/24 套有，≤20% 覆盖 |

## 四、可印证指标（复用后怎么证明「这就是这套风格」）

`scripts/style_fingerprint.py` 的 `verify(style_id, pipeline_dir)` 除了核音效/花字，
现在还核视觉处理（`visual_checks()`，`--visual` 只看这一段）。逐项 PASS/WARN/FAIL：

| 指标 | 怎么量 | 判据 |
|---|---|---|
| `cutout_scope` | EDL 里 `pip_layout.cutout=True` 的镜头角色 | 有非 a_roll → FAIL |
| `cutout_share` | 抠像时长 ÷ a_roll 时长 | > 真值人物层被抠比例 ×1.15 → FAIL；真值 >0 而这次 0 → WARN；真值 0 而有抠像 → FAIL |
| `speed_aroll_lock` | EDL 里 a_roll 且 speed≠1 | >0 → FAIL |
| `speed_values` | 出现过的倍速集合 | 不在真值倍速 ±0.15 → FAIL |
| `speed_usage` | 变速段数 | 真值有而这次 0 → WARN |
| `transition_hard_cut` | `treatment_policy.transition.applied` + 原生草稿 transition 引用数 | ≠0 → FAIL |
| `overlay_stickers` | 原生草稿 sticker 轨：条数/分钟、单条时长 | 有草稿才量；超真值 ×1.5 → FAIL；真值 0 而有 → FAIL |
| `effect_usage` | 原生草稿 effect 轨：条数/分钟 | 同上 |

用法：

```bash
python3 scripts/style_fingerprint.py --style style_21 --pipeline-dir <项目>/pipeline          # 全量核对
python3 scripts/style_fingerprint.py --style style_21 --pipeline-dir <项目>/pipeline --visual # 只看视觉处理
python3 scripts/style_fingerprint.py --style style_21 --visual                               # 只看该风格应有的视觉指纹
```

没有 `04_edl.json` 时视觉项记 WARN（不判 PASS），说明「这次只核到音效花字」；
没有导出原生草稿时贴纸/特效记 WARN，说明「未核」。**风格套错能当场看出来**：
拿 style_15 的指纹去核一份 style_21 的成片，`cutout_share`/`speed_values`/`overlay_stickers` 会立刻报偏差。

**已知边界**

- 画面内容判定依赖抽帧判读（`00_visual_index.json` / `00_inventory.json`）。判读缺描述时只能按
  人脸尺寸判（`basis=face_only`），"正在给人看效果图"这类事故会退化成查不出来——补判读是前置条件。
- 台词侧的「指认画面」判定用的是词表（这个/看/效果/图纸…），真值精度 97%（72 段里 2 段例外），
  不是语义理解；新行业的黑话需要往 `DEICTIC_TERMS` 里补词。
- 贴纸/特效的核验要等导出原生草稿；只有 EDL 时这两项记 WARN，不假装核过。
