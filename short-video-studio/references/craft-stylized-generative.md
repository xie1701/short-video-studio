# 风格化渲染、程序生成与无缝循环工艺规范（Stylized & Generative Craft）

> 适用场景：水墨国风、纸张拼贴、胶片/报纸网格、极简颗粒/热力场/粒子仿真、需要首尾无缝循环的背景层与独立片头。

---

## 一、 风格拆解“四元组”法（拒绝口号式伪风格）

无论需求指定何种视觉美学（或需贴合风格谱中某种质感），禁止仅用“矢量色块加点渐变”应付，应拆解为以下 4 条可执行规则：
1. **物质基底（Material）**：画面承载于什么物理材质？（宣纸与湿墨、手工剪裁卡纸与投影、旧报纸网点、拉丝深色铝板、胶片微颗粒）。
2. **笔触或轮廓生成方式（Mark）**：边缘是如何画出来的？（按中心样条 × 压力包络生成细-粗-细毛笔轮廓；轻微粗糙锯齿与投影表现剪纸边；规整对齐像素栅格）。
3. **有限角色色板（Palette）**：明确每个 Hex 在画面中的职责（纸底、主体墨/前景、单一印章强调、阴影压暗）。
4. **反模式禁忌（What It Is Not）**：明确规定“不是什么”（例如：“纸张拼贴不是纯平无阴影的方框；像素风绝对不能开启抗锯齿模糊”）。

---

## 二、 稳定性三大反闪烁铁律（代码制片最高频陷阱）

1. **纸纹、笔触、纤维纹理离屏一次渲染，整片复用**：
   - 将低频值噪声（Mottling）、数百条微曲纤维及轻微纸颗粒预先画到一张比画布略大的离屏 Canvas / 图层缓存中，渲染循环直接贴图叠加（或做固定平滑偏移），**严禁每一帧循环重新调用随机噪声生成器**。
2. **主体剪影可读性永远高于风格装饰（Subject Before Style）**：
   - 上纹理前先确保在“纯黑剪影 + 白底”或缩略图尺度下，核心对象轮廓依然清晰可辨；纹理叠加压制在低透明度衬底，绝不能用花哨纹路淹没主体与关键文字对比度（仍须过黑盒 WCAG `>= 4.5:1` / 单框 `>= 3.8:1`）。
3. **物理与粒子仿真固定步长预烘焙**：
   - 任何带速度衰减、碰撞反弹、群聚或重力积分的系统，必须在初始化阶段按固定 `step = 1/60` 或 `1/30` 用给定种子一次性跑完整个时间轴并记录帧快照；`seek(t)` 只做读取插值。

---

## 三、 无缝循环（Seamless Loop）数学构造法则

当任务要求生成无缝循环背景、片头循环卡或可无限拼接空镜（周期为 `P` 秒，`N = round(P * fps)` 帧）时：
1. **实际只渲染帧 `0 .. N - 1`**：帧 `N` 必须刚好衔接回到帧 `0` 的下一连续状态（注意：**绝非**帧 `N-1 == 帧 0`，而是周期函数在 `P` 处闭合，以免首尾连播卡顿一帧）。
2. **所有运动周期整除 `P`**：旋转角度设为 `2π * k * t / P`；正弦呼吸设整数圈 `k`。
3. **粒子生命周期取模 `P`**：一个寿命为 `L`（整除或对齐周期）的粒子在出生时间 `birth` 后，当前局部年龄计算为 `((t - birth) % P + P) % P`，确保跨边界 `t = P` 衔接无缝。
4. **噪音采圆映射（Circular Field Sampling）**：如需 2D 连续场循环，在 3D/4D 连续噪声中沿 `(cx + r*cos(2πt/P), cy + r*sin(2πt/P))` 闭合圆路径采样，首尾梯度零跳变。
5. **交片验收法**：在末帧（第 `N-1` 帧）之后紧接拼接第 `0`、`1` 帧连看，确认没有位置、透明度或粒子的突兀跳变。
