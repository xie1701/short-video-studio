# 零实拍知识讲解动画工艺手册

> 适用场景：用户只给一个知识选题、反常识问题或一句话想法，从零产出电影级发光线描知识讲解动画（支持「无配音字幕旁白」与「配音同步」双模式）、双比例 4K 代码封面及分平台发布文案包。

---

## 一、 确定性舞台契约（不可协商）

1. **纯时间函数 `render(t)`**：任意时刻画面仅由 `t` 决定，严禁 CSS `transition/animation`、`setTimeout/setInterval`、`requestAnimationFrame` 驱动逻辑、`Math.random()` 与 `Date.now()`。
2. **双时钟防运动模糊重影**：子帧运动模糊（`--blur 8 --shutter 0.5`）时，舞台同时收到子帧时刻 `t` 与帧中心时刻 `SVSStage.frameT`。滚动数字、底部字幕、角标读取 `SVSStage.frameT` 或 `SVSStage.step(t, 12)`，避免重影。
3. **加载期预热 + CPU 光栅锁定**：Canvas 统一 `{ willReadFrequently: true }`；精灵、光雾纹理与全部 `@font-face` 在第 0 帧前完成加载，字体缺失直接报错不静默回退。
4. **三拍跳转纯函数校验**：正式渲染前运行 `capture_html_video.mjs <stage_dir> --verify`，确认同 `t` 连拍与远跳后跳回的画面在光栅容差（`<=12`）内完全一致。

---

## 二、 六层视觉秩序与每帧信息预算

“高级感”来自**多层次且有秩序的细节**（一个主角最亮最大，其余逐级退后），而非空旷或满屏同样亮：

| 层级 | 内容 | 亮度/对比定位 |
| :--- | :--- | :--- |
| ① 背景氛围 | 预烘焙 `domain-warp fbm` 光雾/星云（压暗、克制） | 最暗（5%–20%） |
| ② 环境运动 | 三层视差星空、微尘、蓝图细网格（永动不抢戏） | 暗（10%–35%） |
| ③ 主体视觉 | 占画幅 30%–60% 的有体积材质球/发光线描/实验装置/真实感界面 | 最亮最大（100%） |
| ④ 信息层 | 关键词大字、等宽滚动读数、引线标注、出处小字 | 标注 40%–75% |
| ⑤ 框架层 | 极淡左上角章节角标 | 很淡（30%–50%） |
| ⑥ 前景质感 | 虚焦光斑、24fps 确定性胶片颗粒、暗角、受控闪白/震屏 | 克制叠加 |

### 每帧信息预算上限（防看板感与文字过载）
- **主角**：每帧仅 1 个（或 1 组同类物作整体），严禁把全身火柴人小人当万能默认主体，改画此刻最有信息量的局部或物件（眼睛、手、账单、实验装置、手机界面）。
- **大字**：1 处；**小字标注/出处**：≤2 处；**底部字幕**：永远 1 行。
- **冷开场（0–5 秒）与片名卡**：小字 0 处，只有主角 + 大字金句 / 发光片名，把注意力锁死。
- **反毛刺铁律**：球体/细胞/星体边缘严禁撒零碎亮点毛刺，必须用贴边向外平滑衰减的连续大气辉光；同一几何母题（圆环/柱状/网格）全片最多用 2 次，正面整圆构图最多 2–3 次。

## 三、 节奏、双字体路由与暗底亮度指纹

1. **前 5 秒金句 + 结尾回环**：0.3s 起出第一句大字金句（每句 ≤16 字），5 秒内出完 1–2 句，接 3 秒发光宋体片名海报卡；结尾回到开篇画面，用新的理解重看同一物体。
2. **字幕即旁白规范**：
   - 无配音模式停留公式：`hold = 0.9 + 字数 / 6`（约 2.5–3.5s/句），底部居中单行（横版 52px / 竖版 44px），**句末自动去标点**（保留成对闭合引号与 `[高亮]`）。
   - 双字体路由：理性/科技/数据/机制选无衬线（`sans`），人文/历史/心理/情感选宋体（`serif`）。
3. **量化视觉秩序门禁（`knowledge_animator.py audit`）**：
   - **6×6 分区 15fps 死区检测**：任意非有意停留区连续 >2.5s 无局部变化即告警；
   - **暗底亮度指纹**（去底部 15% 字幕带）：亮部峰值 `p99 ≥ 130`、高亮像素（>110）约 `1.5%–2.4%`（>4.5% 过曝）、整体均值约 `17–24`、近黑帧占比保留 `17%–39%` 明暗呼吸。
   - 每 15–25s 安排一次奇观帧，奇观后留 0.8–1.5s 暗场呼吸；联系表连续 3 格雷同即切换对数相机机位或插入 1.5s 微观放大镜。

## 四、 运动静态化双盲审片与双比例 4K 封面

- **双盲审片包（`knowledge_animator.py review-pack`）**：自动导出 2s 节奏联系表 + 每个场景切点 `±0.5s` 每 `0.1s` 一格转场条带（专查双层叠影残影）+ 每个场景中段 `0.9s` 每 `0.1s` 一格运动条带（专查缓动与死画面）+ 剥离自评段落后的审片指引。
- **单源双比例 4K 代码封面（`cover_4k.html`）**：
  - 横版 16:9（`3840×2160`）：主体与三层文字（钩子句 / 发光金句 ≤8 字 / 片名）**100% 锁定中央 4:3（`x∈[240, 1680]`）**，左右各 12.5% 仅放氛围；
  - 竖版 3:4（`2160×2880`）：四周留边 ≥60px；
  - 越界自动触发 `COVER_OUT_OF_SAFE` 报错；红线核查图物理隔离在 `work_checks/`，不混入交付成果。
