# 风格复用的契约：每类处理都必须有「凭什么出现」

> 这份文档回答一个只有一句话的问题：**风格模版凭什么可以复用到别的素材上？**
> 答：因为模版里每一类处理（音效、花字、转场、抠像、变速、贴纸、特效、调色、刀法）
> 都不是「风格有这个能力就每镜都上」，而是各自带着一组**条件**；没有条件满足就不上，
> 上了就要说得出参照点在哪。

用户原话（2026-11-24）：

> 「风格模版应该好好抽象下这些音效、花字之类的是要在什么情况下才会出现，调用的原则是怎样，
> 作用域又是怎样，而不是无脑的硬植入。所有的 24 个风格模版也都要反思。风格模版是要围绕
> 着怎样可复用而成立，复用后又从哪些点可以印证这就是对应的风格。」

---

## 一、四问：每类处理都要答上

对每一类处理，模版必须能回答这四个问题，缺一条就不许进模版。

| 问 | 要落成什么 | 反例（会被判为「假模版」） |
| :-- | :-- | :-- |
| **① 触发条件** 什么情况下才出现？ | 可执行的判定：参照点（切点/花字出现/字幕换行/节拍/关键词/画面内容）+ 阈值 | 「每隔 2 秒来一条」——没有任何参照点，只是密度 |
| **② 调用原则** 凭什么选它、凭什么不选？ | 取舍规则：优先级、互斥、降级顺序、缺料时怎么办 | 「有素材就用」——缺料时拿航拍凑数 |
| **③ 作用域** 作用在哪些镜头上？ | 允许/禁止的镜头类型、密度上限、最小间隔、时长上限 | 「全片都套」——把讲解图纸的镜头也抠像 |
| **④ 可印证指标** 复用后怎么证明「这就是这套风格」？ | 可测的指纹：出现密度、占比、配比、中位数，套错风格能当场看出来 | 「看起来像」——无法验证 |

四条里最容易漏的是第 ④ 条。模版抽象完必须能自证：拿一份新片子的产物，
不问人、只看指标，就能说出「这是 style_21，不是 style_03」。

## 二、可复用成立的三个前提

1. **条件对着素材说，不对着文件名说。** 「这一镜画面里正拿着效果图」是条件；
   「第 5 条素材」不是。素材换了，条件照样成立。
2. **缺料要降级，不许跳过，也不许凑数。** 本风格没有这个角色的音效 → 本片不放这一声，
   而不是借别的风格；这一镜没有人物主体 → 不推近，而不是随便找个窗口。
3. **条件优先于风格。** 风格说「要抠像」是能力，不是指令；能力要不要用，看这一镜满不满足条件。
   这条是用户 2026-11-23 定下的硬规矩（见 `style-template-application.md`），
   在这里进一层：**满足条件才上，是模版的语义，不是「偏离风格」。**

## 三、各类处理的条件在哪看

| 处理 | 条件表 / 代码 | 说明 |
| :-- | :-- | :-- |
| 音效、花字 | `treatment-conditions-sfx-flower.md`、`forensic/style_trigger_rules_sfx_flower.json`、`scripts/sfx_policy.py`、`scripts/flower_policy.py` | 触发点归属（切点/花字/字幕换行/节拍）、最小间隔、密度上限、静音段与口播中段禁响 |
| 转场、抠像、变速、叠加贴纸、画面特效 | `treatment-conditions-visual.md`、`forensic/style_trigger_rules_visual.json`、`scripts/treatment_policy.py` | 转场默认禁用（源草稿 24/24 为 0，只有用户放行或素材自带溶接才允许）；抠像要有主体、画面里不能正给人看图纸/屏幕；变速只动 B-roll 不动 A-roll；贴纸/特效只在真值出现过的段落 |
| 字幕（字体/字号/投影/位置） | `forensic/text_style_truth.json`、`scripts/glyph_fallback.py` | 字体按**实际文案的字形覆盖**选 + 逐字回退；缺字 fail-closed |
| 调色 | `forensic/style_render_truth.json`、`scripts/step7_color_grade.py` | 源草稿没有调色就不许凭空调色；肤色必须留在 BT.709 健康扇区 |
| 刀法（镜长/切点/B-roll 占比） | `forensic/style_edit_grammar.json`、`scripts/edit_grammar.py` | 按真值但内容优先：B-roll 对不上台词就回人物镜头 |
| 口播干净度 | `scripts/off_mic.py`、`scripts/script_align.py`、`scripts/audio_cleanliness.py` | **只有对着麦说话的主讲人算口播**：离麦电平掉 18dB 以上、连续 0.8 秒以上、且成稿里对不上的，一律不算 |

## 四、口播这一条的由来（为什么它也算「风格条件」）

用户 2026-11-24 实测：「仲有好多人中意我哋嘅干炒蚝，同埋」是导演/摄影师的话，要去掉。
查实根因不是 ASR 听错，而是**声源离麦 15–33dB**：主讲人对着无线麦，电平稳定在 -15 ~ -20dB，
那段插话掉到 -30 ~ -49dB，ASR 照样把它听成了通顺的一句。

所以口播干净度不能只靠「文字对不对得上成稿」——插话如果碰巧通顺，就一路混进成片。
判据改成两层的：

- **离麦电平**（确定性信号）：同一源文件统一算主讲人基准（字的电平 90 分位），
  落差 ≥18dB 记硬档，8–18dB 记轻档；
- **再叠两个条件才真下刀**：硬档 + 连续 ≥0.8 秒 + 这段字在成稿里对不上（重合率 ≤60%）。
  加后面两条是因为主讲人自己转头/弯腰也会掉 20dB+，只按电平会把
  「岭南元素」切成「岭南元 | 素」、「原汁原味」切成「原 | 汁原味」（实测栽过）。

## 五、复用的验收清单（人工核对用）

1. 成片里每一条音效、每一朵花字、每一次抠像/变速/贴纸，产物里都有 `reason` 与参照点；
   拿不出参照点的条数应当是 0。
2. 24 套里换任意一套，指纹（音效角色配比 / 花字版式配比 / 抠像占比 / 变速段占比 / 镜长中位数 /
   字号 / 色板）应当逐项落在该套真值的容差内；套错风格能被指标抓出来。
3. 缺料的情况要能在产物里看到 `dropped` 与原因，而不是静默少一条。
