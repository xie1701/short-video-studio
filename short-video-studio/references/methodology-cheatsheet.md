# 短视频内容与文案方法论速查手册 (Methodology Cheatsheet)

> 唯一方法来源：[建立可循环的内容系统.md](./建立可循环的内容系统.md)（欧阳编导思维笔记）。
> **硬性约束**：使用 `short-video-studio` 生成任何选题规划、内容日历、口播文案或分镜脚本时，**必须显式标注所采用的公式名称、5A层级、话题方向与切入点**，严禁脱离方法论凭空捏造。

## 一、 双轨判定与北极星指标

首次对话必须通过“先猜后确认”判定用户所属轨道（不问开放题）：

| 维度 | 门店轨 (Store Track) | 博主轨 (Creator Track) |
| :--- | :--- | :--- |
| **典型用户** | 实体店老板、本地生活服务商家（餐饮/美业/汽修/家装/教育等） | 个人创作者、知识IP、泛娱乐/垂直领域达人 |
| **定位模型** | 偏向 `to c`（到店/产品）或 `to b`（定制服务/B端方案） | 偏向 `曝光`（大众流量/泛娱乐/粉丝群体 -> 广告/打赏/带货） |
| **成功标准 (北极星)** | **评论区咨询、私信留资、核销到店** | **3 秒留存率、完播率、净涨粉率** |
| **优先公式** | 主打**水桶流**（人格化信任+细节到店）+ 局部**漏斗流**（同城流量词） | 主打**漏斗流**（自带流量话题+强相关干货）+ **高情绪/强认知开篇** |
| **账号搭建要点** | 头像=门店Logo/老板真人；名称=行业+品类+昵称；背景图=5/1官方广告位（门店/工作图）；简介=背书+愿景+产品服务+怎么找到你（电话/店名） | 头像=个人高清辨识度照；名称=领域标签+昵称；背景图=核心人设与代表作；简介=身份背书+核心价值+更新频率 |

## 二、 创作前整理：用户定位与客户五层问题

### 1. 定位三维度与六大社会特征
- **变现方向**：
  - `to b`：决策层/采购/市场总监 → 定制化服务/品牌合作/B端解决方案 → 行业洞察/案例拆解/企业级价值输出
  - `to c`：年轻消费力/兴趣圈层 → 产品/到店 → 到店理由（围绕产品、门店等）
  - `曝光`：大众流量/泛娱乐/粉丝群体 → 广告/打赏/带货 → 热点话题/趣味互动/跨界联动
- **社会特征 6 维拆解**：`年龄` | `性别` | `地理位置` | `职业` | `收入/消费能力` | `家庭角色`

### 2. 客户的五层问题（选题深度挖掘工具）
生成深度转化文案（尤其 A2/A3 内容）前，必须先拆出这五层：
1. **客户想要什么**（表层需求，如：他想要修车）
2. **他为什么想要这个**（直接触发，如：车坏了他开不了）
3. **这背后真正在意什么**（深层动机，如：想安全上路，不想半路抛锚）
4. **他最怕什么**（核心顾虑，如：怕被坑，花了钱还修不好）
5. **什么才能让他放心**（信任锚点，如：找一个靠谱、说实话不忽悠的老师傅）

### 3. 找对标与真实选题池
- 扒**同行的评论区问题**（有咨询的直接转化为选题）；
- 统计**自己的私信和评论区**高频提问。

## 三、 5A 人群与三阶段内容配比（4周内容日历核心算法）

| 5A 层级 | 对应内容类型 | 典型参考形式 |
| :--- | :--- | :--- |
| **A1（了解人群）** | 泛流量型内容 | 热点话题（最近网上都在传…你看我们店）、同城事件（最近XX人都在传…）、视觉美食/强感官特写 |
| **A2（吸引人群）** | 人设信任型内容 | 老板口播（我是谁/做了多少年）、创业故事、基础知识科普（怎么辨别真假/好坏） |
| **A3（咨询人群）** | 垂直说服型内容 | 深度知识科普、答疑解惑（人均/价格/门店基本信息）、顾客见证（老客来吃了几年）、场景展示（服务过程/环境） |
| **A4（行动人群）** | 售后关怀型内容 | 服务场景展示、售后服务（发生问题怎么解决、感谢支持） |
| **A5（铁粉人群）** | 粉丝互动型内容 | 新品发布、粉丝福利（精神股东共创） |

### 三阶段配比标准（4周按 20 条或 28 条日更排期按比例落位）
- **阶段一（起号冷启动）**：`A1 泛流量 50%` + `A2 人设信任 30%` + `A3 垂直说服 20%`
- **阶段二（稳态成长/放量转化）**：`A1 泛流量 30%` + `A2 人设信任 40%` + `A3 垂直说服 30%`
- **阶段三（私域复购/成熟门店）**：`A2 人设信任 20%` + `A3 垂直说服 30%` + `A4 售后关怀 30%` + `A5 粉丝互动 20%`

## 四、 两大视频核心公式

1. **漏斗流视频公式**（先抓大流量，再漏斗筛客）：
   - 简版：`一个自带流量的话题 + 和话题强相关的内容 + 自然的植入产品`
   - 完整 5 段：`[话题钩子] + [内容展开] + [专业植入] + [人设露出] + [价值升华]`
   - 话题拓展 3 法：目标人群关联身份话题 / 消费场景关联法 / 生活角色关联法
2. **水桶流视频公式**（用产品细节与老板人设筑起信任水桶，让精准客主动买单）：
   - 逻辑链：`产品细节 → 老板靠谱 → 信他 → 买`
   - 完整 5 段：`[精准人群钩子/开篇钩子] + [细节展示] + [人格化表达] + [价值说明] + [转化指令]`

## 五、 选题与文案工具箱（标注清单）

### 1. 六大话题选题方向
1. **社会话题**：`行业 + (时代变化/性别议题/城市话题/社会情绪/热点事件)` 或 `名人名牌名企名校 + 赛道现象`
2. **身份话题**：`在城市 + 身份/收入/年龄/消费 + 算什么水平` 或 `行业弱势群体 + 痛点问题`
3. **认知话题**：`先提出行业固有常识 + 反向拆解颠倒它`
4. **内幕话题**：`行业 + 不敢说的秘密 / 不会告诉你的真相 / 暗箱操作`
5. **争议话题**：`行业 + (性别对立/地域对立/关系对立/财富对立/头牌对立/内外行对立)`
6. **情绪话题**：`人群 + 痛点场景产生的(委屈/无奈/愤怒/心酸/憋屈)`

### 2. 开篇钩子八大切入点
1. **人群切入**：`身份标签 + 应该做什么/注意什么/揭秘 + 核心话题/承诺`
2. **痛点切入**：`你是不是遇到过(痛点场景) + 糟糕的感受/结果`
3. **效果切入**：`方法/产品 + 时间/条件 + 惊人效果/承诺`
4. **情绪切入**：`情绪/感受词 + 引发情绪的事件/对象 + 解决方案/共鸣点`（四大强能量情绪：争议/共情/恐吓/痛苦）
5. **好奇切入**：`反常识/反认知结论 + 暗示有内幕/原因`
6. **身份推荐切入**：`权威/资深/亲临者身份 + 时间/经验 + 自我总结/教你/揭秘 + 价值点`（达人推荐或真实用户见证）
7. **颠覆切入**：`先说行业常识 + 其实/但是(直接颠倒)`
8. **疑问切入**：`为什么/怎么样 + 一个普遍存在的难题/现象`

### 3. 人格化表达六大切入点
1. **性格**（不做完美老好人，立住标签：`较真型` / `倔强型` / `温柔型` / `直爽型`）
2. **初心**（当初为什么做这行）
3. **原则**（坚持什么、绝不做什么的底线）
4. **经历**（走过什么弯路/故事）
5. **价值观**（底层信念，“我认为什么是对的”）
6. **态度**（对当下具体行业乱象或事件的立场）

### 4. 开篇执行细节与十大开篇技巧
- **开篇铁律**：
  1. **第一眼永远大于第一句话** → 首帧画面信息密度必须足够高！
  2. **前 3 秒多场景高密度** → 开头三句有噱头的话，放在三个不同场景切换（工程上对应前 3 秒至少 2 次画面变化）；开头先让观众听得懂。
- **十大开篇技巧**：
  `不字开头` | `制造敌人` | `做嘴替` | `信息缺口` | `对立面开篇` | `对赌开篇` | `信息密度开篇(场景/时间/痛点/人物/身份/环境/事件/爆款元素 选4叠加)` | `数字开篇` | `稀缺性开篇` | `冲突开篇`

### 5. 中间结构与结尾类型
- **中间结构框架**：`观点+原因+案例+观点` / `人格化表达` / `结果+原因+为什么`
- **中间衔接句式**：`提问式`(为什么呢/所以呢/还有呢/比如呢/真的假的/你会怎么做/总结一下啊) / `案例式` / `补充式` / `反转式`
- **四大结尾类型**：`金句结尾` | `感悟结尾` | `互动结尾` | `人设结尾`
