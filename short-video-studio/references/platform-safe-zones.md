# 竖屏短视频平台 UI 遮挡区与包装预算规范

标准成片画布尺寸：**1080 × 1920**（9:16 竖屏，30 fps 恒定帧率）。

---

## 一、 平台 UI 遮挡危险区（兼容抖音 / 视频号 / 快手 / 小红书）

所有关键视觉元素（字幕、花字、贴纸、数据图核心文字、拍摄任务卡主体）**严禁**进入以下像素坐标区：

| 危险区域 | 坐标范围 (基于 1080×1920) | 平台遮挡原因 |
| :--- | :--- | :--- |
| **顶部状态/搜索栏区** | `Y: [0, 160)` | 状态栏、返回键、搜索栏、直播/同城角标 |
| **右侧互动按钮柱** | `X: (880, 1080], Y: [680, 1520]` | 头像关注、点赞、评论、收藏、转发、旋转唱片 |
| **底部信息与进度条区** | `Y: (1480, 1920]` | 账号名、视频文案、POI定位/团购锚点、进度条、底部 Tab |
| **左侧极边缘** | `X: [0, 60)` | 手机曲面屏边缘裁切容错 |

### 安全区 (Safe Zone) 黄金坐标（`common.py` 单一事实源）
- **通用安全区 `SAFE_ZONE`**：`X: [60, 880]`，`Y: [160, 1480]`（用于标题封套、花字、卡片与全片通用视觉要素）。
- **主字幕权威安全区 `SUBTITLE_SAFE_ZONE`**：`X: [80, 860]`，`Y: [1180, 1468]`（基线通常处于 `1220–1360`，即使两行大字也不得超出 `Y = 1468`；四端 render / 剪映 / HyperFrames / QA 统一消费 `final_bbox`）。
- **首帧高密度大字标题卡安全区**：落入 `SAFE_ZONE` 上半屏 `Y: [180, 960]`（确保前 1 秒视觉焦点与人物避脸协同），Step 9 同步导出 `09_ui_safe_preview.jpg` 遮罩预览图与 `180px` 缩略图可读性校验。

## 二、 四套内置可商用字幕样式模板

配置定义于 `assets/subtitle_templates/templates.json`：

1. **`store_bold_yellow`（门店爆款醒目黄）**：
   - 默认用于**门店轨**（美食/本地生活/实体店）。
   - 主文字白色加粗 + 深黑 4px 描边 + 半透明圆角底衬；关键词放大 1.2x 并高亮为 `#FFD54F` 亮黄。
2. **`creator_clean_white`（博主质感极简白）**：
   - 默认用于**博主轨**（知识干货/口播观点/Vlog）。
   - 干净白字 + 细腻阴影；关键词高亮为 `#4FC3F7` 天青蓝或 `#FFB74D` 琥珀金。
3. **`contrast_red_punch`（强反差争议红黑）**：
   - 用于颠覆认知、内幕揭秘、制造敌人等强钩子视频。
   - 白字配高饱和红底标签高亮 `#FF3B30`（仅高亮核心痛点词）。
4. **`warm_persona_cream`（温情人设暖米色）**：
   - 用于创业故事、初心、原则等水桶流人格化表达视频。
   - 暖米白 `#FFF8E7` + 柔和棕黑描边 + 暖橙高亮 `#FF8A65`。

## 三、 包装预算上限与首帧信息密度规则

1. **包装预算上限（防止过度包装成“牛皮癣”）**：
   - 视觉包装元素（花字 + 贴纸 + 特效）**只允许**放在 `03_audio_events.json` 标注的情绪点 (`hook`, `emotion`, `twist`) 或核心信息点 (`keyword_accent`, `data`) 上。
   - 全片视觉包装总量上限：`max_visual_elements = max(3, ceil(duration_sec / 3.5))`（例如 20 秒视频最多 6 个视觉包装元素）。
   - 任意连续 3 秒窗口内不超过 2 个贴纸/花字。
   - 包装元素出现帧必须对齐对应的音效点 (`sfx_cue`) 或重音帧 (`keyword_accent`/`stress`)，允许误差 **`±1 帧`（≤ 33.3 ms）**。
2. **首帧画面信息密度**：
   - 第一帧（`t = 0.0s`）必须同时满足至少两项视觉锚点：清晰主体（人物/产品）+ 首帧重点视觉大字钩子/角标（位于安全区内），严禁黑帧、纯色空屏或无重点的远景过渡帧。
